# Product Images

This folder contains the product images for the shopping application.

## Image Files Needed:

1. **iphone-15-pro.jpg** - iPhone 15 Pro product image
2. **macbook-air-m2.jpg** - MacBook Air M2 product image  
3. **airpods-pro.jpg** - AirPods Pro product image
4. **apple-watch-series-9.jpg** - Apple Watch Series 9 product image
5. **ipad-pro.jpg** - iPad Pro product image

## Image Specifications:
- **Format**: JPG or PNG
- **Size**: 400x300 pixels (recommended)
- **Quality**: High quality product photos
- **Style**: Clean, professional product shots

## Instructions:
1. Download product images from your preferred source
2. Rename them to match the filenames above
3. Place them in this `static/images/` folder
4. The application will automatically use these local images

## Fallback:
If any image file is missing, the application will show a placeholder with the product name.
